# Theme Studio 0.5.0 — Preview

## English

Reference build: **Blender 5.2.1 LTS `9e2066aef7ef`**. This remains a legacy add-on
ZIP, not a Blender Extension. Blender 5.3 is experimental, not verified for v0.5.

### Changes

- Accepted smart-color fixes and category/context Details organization.
- Hybrid workspace by default, with full N-panel and Preferences > Themes options.
  Existing saved workspace choices are preserved.
- Theme selector, source identity and persistent session/save outcomes.
- Native theme save/load/export. Save writes matching XML files to the selected
  library's `themes` folder and Blender's user presets. Editable projects stay separate.
- One Finish dialog: save-and-finish primary, keep/discard under alternatives.
- Recovery discovery works during restricted native add-on registration.
- English UI with native Italian translation.

### Install and verification

Install **`theme_studio-0.5.0.zip`** from Preferences > Add-ons > Install from Disk,
then enable Theme Studio. Do not use GitHub's automatic source archives. This ZIP
is byte-identical to the verified local r2 candidate; older packages are unchanged.

- 430 Python tests passed.
- Eight isolated installed-ZIP checks passed on the reference build, including
  simulated interrupted-session recovery, blocked editing before resolution and
  exact restoration of 802 fields and auto-save, followed by disable/removal.
- Earlier focused native save/Finish checks and positive user acceptance are
  separate evidence, not claims that every context or theme was tested.

### Known limits

- Recovery was simulated in one process, not tested through a real crash/restart.
- Initial enum setup warnings were recorded in earlier native checks.
- Existing screenshots/demo predate v0.5 navigation and session controls.
- Picker remains inactive; Asset Browser theme assets and future shortcut buttons
  are not included. The HSV-wheel outline ignores stored alpha. Derived text may
  remain gray when black is selected; universal contrast is not promised.
- Theme edits are global. Do not save Blender preferences during temporary
  preview. Finish or discard before closing Blender. A theme XML save does not
  save all preferences or guarantee the active theme at next startup.

## Italiano

Build di riferimento: **Blender 5.2.1 LTS `9e2066aef7ef`**. Resta uno ZIP addon
legacy, non una Blender Extension. Blender 5.3 è sperimentale, non verificato per v0.5.

### Novità

- Fix smart-color accettati e Dettagli organizzati per categoria/contesto.
- Workspace Ibrida predefinito, con pannello N completo e Preferenze > Temi come
  alternative. Le scelte di workspace già salvate restano invariate.
- Selettore del tema, identità della provenienza ed esiti persistenti di sessione/salvataggio.
- Salvataggio/caricamento/esportazione nativi. Salva scrive XML corrispondenti nella
  cartella `themes` della libreria scelta e nei preset utente Blender. I progetti
  modificabili restano separati.
- Un dialogo Termina: salva e termina principale, mantieni/scarta nelle alternative.
- Rilevamento del recupero corretto durante la registrazione nativa ristretta.
- UI inglese con traduzione italiana nativa.

### Installazione e verifiche

Installa **`theme_studio-0.5.0.zip`** da Preferenze > Add-on > Installa da disco,
poi attiva Theme Studio. Non usare gli archivi sorgenti automatici di GitHub.
Lo ZIP è identico byte per byte al candidato locale r2 verificato; i pacchetti
precedenti restano invariati.

- Superati 430 test Python.
- Superati otto controlli isolati dello ZIP installato sulla build di riferimento,
  inclusi recupero di un’interruzione simulata, blocco della modifica prima della
  risoluzione, ripristino esatto di 802 campi e salvataggio automatico, poi
  disattivazione/rimozione.
- I precedenti controlli nativi mirati di salvataggio/Termina e l’accettazione
  dell’utente sono evidenze distinte, non prove di ogni contesto o tema possibile.

### Limiti noti

- Recupero simulato in un processo, non provato con crash/riavvio reale.
- Avvisi iniziali degli enum registrati nei controlli nativi precedenti.
- Schermate/demo esistenti precedenti alla navigazione e ai comandi di sessione v0.5.
- Picker inattivo; asset dei temi nell’Asset Browser e futuri pulsanti scorciatoia
  non inclusi. Il contorno della ruota HSV ignora l’alpha. Il testo derivato può
  restare grigio scegliendo nero; non è promesso contrasto universale.
- Le modifiche al tema sono globali. Non salvare le preferenze Blender durante
  l’anteprima temporanea. Termina o scarta prima di chiudere Blender. Salvare XML
  non salva tutte le preferenze né garantisce il tema attivo al prossimo avvio.
